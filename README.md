# AAA Mobile Studio

AAA is a mobile-first AI development studio designed to bring an Android-Studio-style workflow to Android phones, with cloud builds and AI assistance.

## Current foundation
- Native Android + Jetpack Compose interface
- Dashboard and project workspace
- Code editor screen
- AI Builder screen
- APK and AAB build screens
- GitHub workspace screen
- Settings screen
- GitHub Actions background APK/AAB builds

## Roadmap
- Real project/file system
- ZIP and GitHub project import
- AI code generation and autonomous fixes
- Monaco/advanced editor integration
- Live web/Android previews
- Remote Android builds with logs
- Supabase authentication and project storage
- GitHub OAuth and repository sync
- Secure AI provider configuration

The mobile app is the control center; heavy Android compilation is handled by cloud runners so the phone does not need the complete Android Studio toolchain installed locally.
